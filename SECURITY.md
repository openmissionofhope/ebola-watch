# Security policy

Please report vulnerabilities privately through GitHub's "Report a
vulnerability" (Security advisories) on this repository. Do not open public
issues for security problems, and do not include real patient or personal data
in reports.

We are particularly interested in: ways to recover suppressed or sub-national
information, ways for fetched content to influence system behaviour (prompt or
pipeline injection), authentication or authorisation bypasses on the
administrative API, and personal data appearing in any output.
